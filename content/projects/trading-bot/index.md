Developed a machine learning pipeline for stock trend prediction using technical analysis indicators on NIFTY50 data. The project involved extracting and preprocessing market data, engineering features using indicators such as MACD, RSI, Bollinger Bands, ADX, and Aroon, handling missing values and normalization, and training models to predict short-term gains and trading positions (buy, sell, or hold).
